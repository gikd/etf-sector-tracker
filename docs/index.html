글로벌 메가캡

전 세계 시총 최상위 ~300개(큰돈도 쉽게 거래 가능한 초대형주)를 직접 섹터 분류. 보기 전환: 섹터(어느 섹터로 돈이 쏠리나 → 그 안의 리더) · 상대강도(유니버스 전체에서 선택 기간 수익률 상위 종목 + 중앙값 대비 강도) · 신고가(52주 고점 −3% 이내) · 신저가(52주 저점 +3% 이내). 기간 버튼은 정렬 기준(1일~YTD, 상대강도는 기본 1개월). 카드엔 올해·내년 예상 PER. 카드 클릭 = 일봉 차트 + 수익률 + 뉴스 상세. 관측용이며 투자 권유가 아닙니다.
